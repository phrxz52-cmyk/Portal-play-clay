# Como usar com Go Live

Este projeto foi preparado para funcionar como página estática com a extensão Go Live do VS Code.

## Passos
1. Abra a pasta do projeto no VS Code.
2. Instale a extensão Go Live.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito e escolha `Open with Live Server` (ou use a extensão Go Live).
5. A página será aberta no navegador local.

## Observações importantes
- O Go Live serve arquivos HTML, CSS e JavaScript estáticos.
- Ele não executa projetos Next.js, React ou Node.js sem configuração extra.
- Por isso, esta versão foi feita em HTML puro para funcionar sem terminal nem instalação de dependências.
